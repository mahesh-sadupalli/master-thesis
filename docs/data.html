Key Observations

  • TKE vs Vy (r = −0.52): Strongest correlation — higher velocity fluctuations associate with lower turbulent kinetic energy
  • TKE vs Vx (r = −0.41): Moderate negative correlation
  • Pressure is nearly uncorrelated with velocity components

Implications for Compression

  • Correlated fields (Vx–Vy–TKE) can benefit from shared representations
  • Pressure’s independence suggests it may need separate attention
  • Multi-output models must balance these varying correlations

Optimizer Convergence on the MSE Loss Surface

All thesis models minimise MSE loss with Adam (lr=0.001). In offline mode the full dataset defines a single convex bowl — Adam converges to the global minimum. In online mode each temporal window shifts the loss surface; without replay the optimizer chases each window’s minimum and overwrites previous knowledge (catastrophic forgetting). Experience Replay stabilises the effective surface so the optimizer finds a compromise minimum.
